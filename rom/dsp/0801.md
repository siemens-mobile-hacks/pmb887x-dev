# PMB8876 DSP Mask ROM 0801 commands

This file describes the MCU-visible commands implemented by DSP Mask ROM
`0x0801`. Addresses are TEAKLite word addresses. The matching images are
[`0801.dsp1`](0801.dsp1) and [`0801.txt`](0801.txt); the inspected startup
firmwares are [`sl98/0801.txt`](sl98/0801.txt) and
[`el71/0801/firmware.txt`](el71/0801/firmware.txt).

  the ARM command writers around `0xA0A74574..0xA0A7633C` and
  `0xA0B1FDBC..0xA0B208BC` in EL71.

The PMB7870 manual defines the public command names and intended operation. It
is not an exact PMB8876 ABI specification. The ROM listing determines the
dispatcher routes and the words actually consumed by Mask ROM. Ghidra provides
the PMB8876 caller-side layouts. Names in square brackets are inferred because
the manual omits those command IDs.

## Transport

### Boot commands

After reset the DSP runs the boot loop at `P:204A`. The command record begins
at shared-memory word offset `SM_BOOT_DATA = 0x002`. The MCU writes the record,
sets MCS communication flag 0, and raises DSP interrupt 0. The DSP clears the
flag after completing the command.

| ID | Name | Handler | Record starting at `SM_BOOT_DATA` | Effect |
|---:|---|---:|---|---|
| 0 | `PLOAD` | `P:2068` | `0, P-destination, length, words...` | Copy up to 507 words from Shared RAM to P-space. |
| 1 | `DLOAD` | `P:206F` | `1, D-destination, length, words...` | Copy up to 507 words from Shared RAM to D-space. |
| 2 | `BRANCH` | `P:2086` | `2, P-address` | Final normal boot command; branch to startup firmware. |
| 3 | `PREAD` | `P:2077` | `3, P-source, length` | Copy P-space to `SM_BOOT_DATA + 3`; maximum length is 507 words. |
| 4 | `DREAD` | `P:207E` | `4, D-source, length` | Copy D-space to `SM_BOOT_DATA + 3`; maximum length is 507 words. |
| 5 | `FAST` | `P:2089` | `5` | Restore the standby-power-down snapshot from `SM_SBPD_*`; valid only after `PW_DOWN`. |

IDs 6 and 7 are rejected by returning to the boot wait loop. The dispatcher
masks the command with `7`, so values outside `0..7` alias one of these entries
and must not be used as extensions.

### Runtime commands

There are three equivalent pipes at Shared RAM word offsets `0x005`, `0x021`,
and `0x03D`. A pipe contains the command followed by 16-bit parameters:

```text
pipe[0] = command
pipe[1] = parameter 0
pipe[2] = parameter 1
...
```

The MCU sets the corresponding MCS communication flag and raises DSP interrupt
0, 1, or 2. On acceptance, the dispatcher replaces `pipe[0]` with
`-command`; on rejection it writes zero. The flag is cleared when the command
has been accepted. Commands `CCH_RX`, `CCH_TX`, `TCH_26`, and `PDCH` are
synchronous: acceptance is immediate, but the new state takes effect on the
next frame interrupt. All other documented commands are asynchronous.

The command table is `D:854E..D:8591`. IDs 1 through 34 and ID 67 enter fixed
Mask ROM handlers. IDs 35 through 66 enter two-word Program RAM trampolines at
`P:1FC0..P:1FFE`, so their final behavior belongs to the loaded startup
firmware, not to immutable Mask ROM.

ABI and behavior:

- `1 FC_INIT`: `MODE, THRSH, HYST`. Configure frequency-correction-burst search mode, threshold, and
  hysteresis.
- `2 MODU_INIT`: `IOFFS, QOFFS, IAMP, QAMP, GMSK_FREQ, DUMMY, IQ_SETUP, UNK7, UNK8`. Configure the
  GMSK modulator. The 0801 handler consumes nine words and writes them to `D:DEB4..D:DEBA` plus internal
  state. The PMB7870 manual documents only the first seven; EL71 supplies all nine.
- `3 IQ_SWAP_1`: `SWITCH`. Enable or disable I/Q swap for normal-burst RX/TX.
- `4 IQ_SWAP_2`: `SWITCH`. Enable or disable I/Q swap for FCB search and sync-burst detection.
- `5 DEC_INIT`: `SWITCH, PAR...`. Select FS, EFR, HS, or AMR channel decoding and copy the mode-dependent
  parameter block. Invalid selectors reject the command.
- `6 CIPH_KEY`: `SWITCH, CIPH, SS, CKEY0..CKEY7`. Update cipher mode, key, or both. A5/3 uses all eight
  key words.
- `7 CCH_RX`: `CIPH, TSC, EARLY, UNK3..UNK6`. Start control-channel receive. The 0801 handler stores seven
  words, while the PMB7870 manual names only the first three. EL71 fills all seven. Synchronous.
- `8 CCH_TX`: `CIPH, TSC`. Start control-channel transmit. Synchronous.
- `9 TCH_26`: `CHT, CIPH, TSC, INIT, PAR1..PAR8`. Start or modify a circuit-switched traffic channel.
  Synchronous.
- `10 LOOP`: `SWITCH, UL_SRC0, UL_SRC1`. Select GSM test loop A/B/C/D/E/F/I or open the loop.
- `11 PDCH`: `TSC, MODE`. Start or modify the packet-data channel. EL71 preloads seven trailing pipe words,
  but the fixed handler copies only the documented two into its PDCH state block. Synchronous.
- `12 [BB_TIMESLOT_CONFIG]`: `PROFILE, TYPE, PRIMARY0, PRIMARY1, CHAN0..CHAN3, RESOURCE0, BUFFER0, ...,
  RESOURCE3, BUFFER3, RESERVED, CONTROL`. `PROFILE` selects one of eight 17-word records through
  `D:80AA..D:80B1`; there is no bounds check. The handler copies the trailing words into that record and binds
  it to scheduler slot `0x10`. EL71 builds the record from an L1 timeslot descriptor: channel types are ordered
  with the selected channel first, unused entries are `0xFFFF`, and resource/buffer indices are scaled by
  `0x00D0`. `RESERVED` is always `0xFFFF` in the inspected caller.
- `13 BB_OFF`: no parameters. Stop modem algorithms and enter baseband idle without stopping audio.
- `14 IDLE`: no parameters. Stop all scheduled algorithms and enter idle; sample-based audio remains active.
- `15 VB_ON`: `SWITCH, VRXCTRL1, VRXCTRL2, VTXCTRL, RATESW, OUT_MODE, CSEL, NUM0, DEN0, NUM1, DEN1,
  RXCONF, TXCONF`. Configure and switch the AFE and I2Sx voice path.
- `16 VB_SET_BIQUAD`: `PAR1..PAR20`. Set four five-coefficient voiceband biquads: input 1/2 and output 1/2.
- `17 VB_SET_GAIN`: `Scal_In, Scal_Out, Side_Ton, Mic_Mute, Scal_Mic, Gain_Out, Scal_Rec, Speech_Mix_DL,
  Ton_Mix, Delta0, Delta1, Kappa0, Kappa1, Lambda0, Lambda1, Scal_AFE, Scal_Mic2, AFE_tone, Ton_Mix_UL,
  Ton_Mix_DL, Speech_Mix_UL`. Set the voiceband gain and mixing matrix.
- `18 VB_START_TONE`: no parameters. Start a tone using frequency, amplitude, duration, and IRQ data from
  fixed Shared RAM fields.
- `19 VB_STOP_TONE`: no parameters. Stop tone generation immediately.
- `20 VB_READ_DURATION`: no parameters. Copy the remaining tone duration to `SM_TONE_DUR_OUT`.
- `21 VB_RESET`: no parameters. Reset voiceband filter state and stop tone generation.
- `22 VB_DAI`: `MODE`. Select normal, vocoder-test, acoustic-test, or voiceband-test DAI mode.
- `23 HF_SET_PAR`: `PAR1..PAR12`. Set hands-free EC, LMS, noise-reduction, and attenuation parameters.
- `24 HF_ON`: `SWITCH`. Independently initialize or enable EC, adaptation, noise reduction, AGC, and related
  modes through bits 0..8.
- `25 VM_CMD`: `VM_MODE, alpha0, alpha1, beta0, beta1, gamma0, gamma1`. Configure or disable voice memo
  mixing.
- `26 VB_SET_CBUF_GAIN`: `Scal_SAPP, Scal_Ext, Mix_AFE, Mix_I2Sx, Scal_PCM`. Set circular-buffer source,
  mix, and PCM gains.
- `27 [BB_CTRL]`: `VALUE`. Write `VALUE` directly to baseband register `D:DE80` (`TEAK_BB_CTRL`), without
  validation or masking. Neither EL71 nor SL98 sends this command through its normal runtime-command API.
- `28 [PCM_SUBMIT]`: no parameters. Arm the sample-based PCM task by setting bit `0x0040` in `D:7DF3` and
  binding the record at `D:7AA2` to scheduler slot `0x1A`. The task processes 160-sample blocks in both
  directions of the active audio conversion path. EL71 issues this command after copying each new PCM block
  into Shared RAM; three independent player implementations use the same sequence. SL98 does not issue it.
- `29 [PDCH_OFF]`: no parameters. Schedule PDCH shutdown in state word `D:78CD`. Its frame handler at
  `P:2FA7` clears scheduler bit `0x0004`, which the PDCH-start path at `P:2F71` sets, then resets PDCH state
  through `P:3247`. The ARM wrapper is `dsp_stop_pdch` at `0xA0B1FE78`.
- `30 DTX_ON`: `SWITCH`. Enable or disable discontinuous transmission.
- `31 PW_DOWN`: no parameters. If idle, save the startup snapshot to Shared RAM and enter standby power-down.
  No further runtime command is accepted; wakeup requires reset, `FAST`, and `BRANCH`.
- `32 WRITE_DSP`: `S_ADDR, D_ADDR, LEN`. Copy Shared RAM offset `S_ADDR` to D-space `D_ADDR`.
- `33 READ_DSP`: `S_ADDR, D_ADDR, LEN`. Copy D-space `S_ADDR` to Shared RAM offset `D_ADDR`.
- `34 WRITE_PROG`: `S_ADDR, D_ADDR, LEN`. Copy Shared RAM offset `S_ADDR` to P-space `D_ADDR`.
- `67 RF_ADAPT`: `BB_NB_FILTER_SWITCH, BB_ADAPT_THRES, SMARTIPATCH, BB_CTRL, UPDATE, PAR0..PAR12`.
  It updates filter selection, sensitivity threshold, SmartiPatch state, `TEAK_BB_CTRL`, and optionally 13
  narrow-band filter coefficients. In the inspected 0801 pair, this fixed command is used while ID 43 rejects.

`BB_TIMESLOT_CONFIG`, `BB_CTRL`, `PCM_SUBMIT`, and `PDCH_OFF` are descriptive working
names, not names recovered from the PMB7870 manual. Their effects above come
directly from the fixed handlers and their downstream frame handlers.

ABI and behavior:

- `35 READ_PROG`: `S_ADDR, D_ADDR, LEN`. Copy P-space to Shared RAM.
- `36 MCU_INT`: the SL98 handler consumes `SWITCH`. EL71 supplies three words and selects the alternate
  handler at `P:44FC`.
- `37 VB_I2Sy`: `SWITCH, CSEL, NUM0, DEN0, NUM1, DEN1, RXCONF, TXCONF, I2Sy_RATE, I2Sy_MODE`.
  Configure the second I2S/DAI path.
- `38 TTY_CTM`: `SWITCH, NO_NEG, AUT_PREAMB`. Configure cellular text telephone mode.
- `39 VB_SYNC`: the SL98 handler consumes `SWITCH, SYNC, PTR_VAL, SYNC_LIM`. The EL71 handler consumes two
  words, masked to two and three bits respectively.
- `40 UMTS_ON`: the SL98 handler consumes no parameters. EL71 supplies four words to its alternate handler.
- `41 MP3`: `SWITCH, PAR1`. SL98 rejects it; EL71 enables the Mask ROM handler at `P:471C`.
- `42 SYNTH`: SL98 uses the manual's `SWITCH, PAR1, PAR2` layout. EL71 supplies one word to `P:4728`.
- `43 RF_ADAPT`: `BB_NB_FILTER_SWITCH, BB_ADAPT_THRES, SMARTIPATCH, BB_CTRL, UPDATE, PAR0..PAR12`.
  SL98 rejects it. EL71 enables the legacy handler, but its normal GSM path sends the equivalent layout as
  fixed command 67.
- `44 AUDIOPOSTPROC`: `SWITCH, b_exp, b1, b0, a1`, followed by compressor parameters. Configure the
  synthesizer shelving filter and audio compressor.
- `45 PCMPLAY`: `SWITCH, PAR1, PAR2, PAR3`. Initialize, stop, or feed the PCM/ADPCM player.
- `46 DTW`: SL98 rejects it. EL71 routes it through loaded handler `P:00DD` to banked Mask ROM `P:CA48`;
  the ARM caller supplies one or three words according to the operation.
- `47 TX_DIG`: SL98 rejects it. The EL71 handler returns without consuming the supplied `SWITCH` word.
- `48 I2S_SWAP`: `SWITCH`. SL98 rejects it; EL71 enables the Mask ROM handler at `P:46A6`.
- IDs 49 through 64 are the manual's `USER_15..USER_0` extension IDs. EL71 enables IDs 49 through 52;
  their recovered behavior is documented in [`el71/README.md`](el71/README.md). The remaining routes reject.
- IDs 65 and 66 are two additional user-extension trampolines. Both inspected startup routes reject. ARM
  function `0xA0B20834` can construct ID 66, but its intended external symbol is not recovered yet.

ID 0 is invalid at runtime because table entry `D:854E` is null. ID 68 is the
first value above the dispatcher limit and is rejected before table lookup.
